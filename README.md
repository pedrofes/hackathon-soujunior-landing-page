# Landing Page Apoia.se — SouJunior

Landing page criada para o Hackathon SouJunior, com o objetivo de engajar visitantes a apoiarem a campanha oficial da comunidade no Apoia.se.

Projeto em desenvolvimento com Next.js (App Router) e React.

## Stack utilizada

- Next.js 16 (App Router)
- React 19
- Tailwind CSS 4
- ESLint 9

## Estrutura do projeto

```
src/
  app/
    layout.js      # layout raiz e metadata
    page.js         # página inicial
    globals.css     # estilos globais / Tailwind
  components/
    sections/
      hero.jsx      # seção hero da landing page
```

## Como rodar o projeto

```bash
npm install
npm run dev
```

Acesse http://localhost:3000

## Scripts disponíveis

- `npm run dev` — inicia o servidor de desenvolvimento
- `npm run build` — gera o build de produção
- `npm run start` — inicia o servidor com o build de produção
- `npm run lint` — executa o ESLint
